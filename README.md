# 🏛️ Demo-Mayor Official Website + Citizen Voice

A modern, responsive, and user-friendly website designed to improve communication between local government representatives and citizens.

The platform allows visitors to learn about the mayor, explore development projects, view official notices, browse photo galleries, and access important municipal information.

Citizens can submit feedback, suggestions, and messages directly through the **Citizen Voice** section. Authorized administrators can review submissions and manage website content through a secure admin dashboard.

## ✨ Key Features

- Mayor profile and introduction
- About Mayor and History pages
- Development projects and activities
- Official notices and announcements
- Photo gallery with album filtering
- Citizen feedback and messaging system
- Secure admin dashboard
- English and Nepali language support
- Nepal time clock
- AD and BS calendar integration
- Light and Dark mode
- Responsive and mobile-friendly design

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- Vanilla JavaScript – Frontend functionality
- Google Apps Script – Backend and API
- Google Sheets – Database and feedback storage
- Google Drive – Image and PDF storage

## 🔐 Administration

The admin dashboard allows authorized administrators to:

- Review citizen feedback and messages.
- Add, edit, and delete development projects.
- Publish and manage official notices.
- Upload photographs and PDF documents.
- Manage photo gallery albums.
- Control published website content.

Administrative access is restricted to authorized Google accounts.

## 🎯 Project Purpose

The main purpose of this project is to make local government information more accessible, encourage citizen participation, improve transparency, and strengthen communication between the mayor's office and the public.
